# 🍻 Central Florida Breweries

A simple web application showcasing breweries across Central Florida, built using Google API and JavaScript.

---

## 🌟 Features

- Interactive map with brewery locations
- Real-time data using Google Maps & Places API
- Clean, efficient JavaScript functionality
- Designed with VS Code for smooth development

---

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed:
- Node.js (if using a server-side framework)
- A text editor like VS Code

### Installation

Clone this repository and navigate to the project folder:
```sh
git clone https://github.com/YOUR_GITHUB_USERNAME/central-florida-breweries.git
cd central-florida-breweries
```

### API Setup

- Obtain a Google Maps API key from [Google Cloud Console](https://console.cloud.google.com/).
- Add the key to your configuration file or directly into your script.
